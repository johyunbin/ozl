# OZL Pulse

매시 5분에 피드를 읽고, 최근 6시간 기사를 사건별로 묶어 신호 네 가지로 순위를 매기는 비공개 도구다. 결과는 `private/pulse/out/now.json` 에 쓰고, 웹 화면과 iOS 앱이 이 파일을 읽는다. 검증 전 신호여서 공개 문서와 사이트에 옮기지 않는다.

## 웹 화면

- 서버: `python -m ozl.pulse serve` — 표준 라이브러리, 읽기 전용, `127.0.0.1:8765` 에만 연다. launchd `com.hyunbin.ozl-pulse-web` 이 상시 띄운다.
- 밖에서 보기: `tailscale serve --bg --http=8765 http://127.0.0.1:8765` 로 tailnet 안에만 연다. 주소는 `http://<기기 이름>.<tailnet>.ts.net:8765/`(`tailscale status` 로 확인 · 같은 tailnet 에 로그인한 기기에서만 열린다). tailnet 에 HTTPS 인증서를 켜지 않아 HTTP 다. 끄기: `tailscale serve --http=8765 off`.
- API: `/api/now`(now.json) · `/api/topic/<id>`(지난 24시간 순위·매체 수) · `/api/health`(마지막 성공 실행과 90분 넘게 멈췄는지).
- 화면: 순위 · 기관 발표 · 급상승어 탭, 국내/해외 필터, 민감 소재 숨김. 5분마다, 그리고 탭으로 돌아올 때 다시 읽는다.

## iOS 앱

- 위치: `apps/ios/OZLPulse/`(SwiftUI · iOS 18 이상 · 외부 패키지 없음). `OZLPulse.xcodeproj` 를 Xcode 로 연다.
- 서버 주소는 앱의 설정 화면에서 넣는다(기기에만 저장 · 저장소에 실제 주소를 두지 않는다). 시뮬레이터는 `http://127.0.0.1:8765` 로 이 맥의 서버에 붙는다.
- HTTP 허용은 `*.ts.net` 과 로컬 주소에만 둔다(`Info.plist`).
- 화면: 순위(등락·신호 막대·민감·슈카 최근 다룸 표시) · 기관 발표 · 급상승어, 상세(신호 값·24시간 순위와 매체 수 차트·기사 링크). 당겨서 새로고침, 앱으로 돌아올 때와 5분마다 다시 읽는다.
- 실기기 설치는 Xcode 에서 개인 Apple ID 로 서명해 직접 한다. 푸시 알림은 넣지 않았다.

## 실행

```bash
.venv/bin/python -m ozl.pulse run          # 수집하고 now.json 을 새로 쓴다
.venv/bin/python -m ozl.pulse run --no-fetch   # 저장된 기사로만 다시 계산
.venv/bin/python -m ozl.pulse run --community  # 회차(하루 2회)용 — 국내 커뮤니티 인기글·실시간 검색어도 받는다
.venv/bin/python -m ozl.pulse show -n 15   # 상위 주제를 표로
.venv/bin/python -m ozl.pulse prune        # 90일 지난 기록 정리
```

예약 실행은 launchd `com.hyunbin.ozl-pulse` 가 `scripts/pulse_run.sh` 를 매시 5분에 부른다. 로그는 `private/pulse/logs/`. 모델은 부르지 않는다.

## 무엇을 읽나

- 기사·기관 원문·급상승어·HN: `src/ozl/research/feeds.yaml` 의 피드 전부(OZL 일일 데스크와 같은 목록)
- 유튜브 인기 동영상(KR): YouTube Data API. 키는 환경 변수 `OZL_YOUTUBE_API_KEY`·`YOUTUBE_API_KEY` 또는 저장소 루트 `.env`(gitignore)에서 읽는다. 키가 없으면 이 신호는 "꺼짐"으로 표시한다.
- 발표 일정: `src/ozl/research/calendar.yaml`
- 국내 커뮤니티 인기글·실시간 검색어: `community.py`. `run --community` 일 때만 받는다(아래 「커뮤니티 수집」).

## 신호와 점수

| 신호 | 켜지는 조건 |
|---|---|
| 보도 | 서로 다른 매체 수, 그리고 지난 1시간에 기사를 낸 매체 수를 그 전 5시간 평균과 견준 속도. 매체 한 곳으로는 켜지지 않는다 |
| 검색 | 구글 트렌드 KR/US 급상승어가 주제 낱말에 들어 있고, 급상승어에 딸린 기사 제목도 주제와 겹칠 때. 대략 검색량이 클수록 높다. 회차 실행에서는 시그널 실시간 검색어도 본다 — 검색어 낱말 2개 이상이 주제에 있고 검색어 낱말의 절반 이상일 때, 1위 0.8에서 10위 0.53까지. 둘 중 큰 값 |
| 커뮤니티 | 묶음에 든 커뮤니티 글(HN·국내 커뮤니티)의 서로 다른 사이트 수와 글 수. 사이트 1곳 글 1건은 0.2로 켜지지 않고, 1곳 3건 0.3, 2곳 0.6, 3곳 이상 1.0. 유튜브 인기 동영상 제목과 낱말 2개 이상 겹치면 1.0 |
| 기관 | 묶음에 기관 원문이 있고 언론도 받았을 때. 언론이 받지 않은 보도자료는 순위에 넣지 않고 "기관 발표" 목록에 따로 싣는다. 오늘 발표 일정과 지표 이름이 겹칠 때도 약하게 켜진다 |

점수는 네 신호의 가중합(보도 0.35, 검색 0.30, 기관 0.25, 커뮤니티 0.10)에, 켜진 신호가 두 개 이상이면 하나당 1.5를 더한 값이다. 매체 한 곳뿐인 묶음은 1.5를 넘지 못한다. 점수는 순위를 정하는 데만 쓰고 사실 여부와는 상관이 없다.

같은 사건은 시간이 지나도 같은 번호(`topic_id`)로 잇는다. 이번 시각 묶음의 기사 하나하나를 지난 24시간 주제의 첫 기사 낱말과 견주어, 겹침이 큰 쌍부터 짝짓는다.

## 알려진 한계

- 같은 사건이 제목 낱말이 달라 두세 묶음으로 갈라지는 일이 있다(묶음 기준은 `collect.cluster` 를 그대로 쓴다).
- 급상승어 연결은 보수적이다. 딸린 기사 제목이 주제와 겹치지 않으면 연결하지 않으므로 연결 누락이 연결 오류보다 많다.
- 커뮤니티 글은 제목이 짧고 말투가 달라 기사 묶음에 잘 들어가지 않는다(묶음 기준: 낱말 3개 이상 겹침). 2026-11-11 실제 수집 1회에서 커뮤니티 글 41건 가운데 기사 묶음과 이어진 글은 없었다.

## 커뮤니티 수집

`python -m ozl.pulse run --community` 일 때만 받는다. 매시 실행(`scripts/pulse_run.sh`)에는 넣지 않는다. 받는 것은 목록의 제목·링크·추천/조회/댓글 수·게시 시각뿐이고 본문·댓글·이미지는 받지 않는다. 소스마다 회차당 요청 한 번, 다시 시도하지 않는다. 실패는 `now.json` 의 `feeds_failed` 와 명령 출력의 상태 줄에 남는다. 커뮤니티 글은 T5 단서로만 쓴다. 민감 소재와 정치 게시판 글은 거르지 않고 표시만 한다.

약관과 robots.txt 는 2026-11-11 에 사이트를 직접 열어 읽었다. 판단 근거는 `community.py` 의 `SOURCES[].terms` 에 있다. 2026-11-14 에 약관을 다시 읽고 시그널, 보배드림, 뽐뿌를 껐다(판정은 출처 대장 `src/ozl/research/sources_ledger.yaml`).

| 소스 | 받는 곳 | 판단 | 근거 |
|---|---|---|---|
| 시그널 | 실시간 검색어 JSON(top10) | 불명 · 끔(2026-11-14) | 이용약관에 자동 수집 조항 없음. 제13조가 영리 목적 무단 이용을 막는다. robots.txt 전체 허용. 공개 문서화된 API 는 아니다 |
| 클리앙 | 모두의공원 추천순 | 금지 · 끔 | 이용약관 제13조③이 권리자 동의 없는 정보 수집·복제·배포를 막는다. robots.txt 가 ClaudeBot·anthropic-ai 와 쿼리 주소를 막는다 |
| 보배드림 | 베스트글 목록 HTML | 불명 · 끔(2026-11-14) | 이용약관에 자동 수집 조항 없음. 제11조③(회원의 의무)이 사전 승낙 없는 정보 복제·사용·제공을 막는다(영리 여부 구분 없음). robots.txt 전체 허용 |
| 뽐뿌 | 자유게시판·정치자유게시판 RSS | 불명(공식 RSS 는 있음) · 끔(2026-11-14) | 사이트가 RSS 를 낸다. 제13조②가 사전 승낙 없는 영리 목적 이용과 제3자 제공을 막는다. `id=issue` 는 정치 게시판이라 글에 정치 표시를 단다 |

"불명"인 세 곳은 2026-11-14 에 껐다. 다시 켜려면 출처 대장의 판정이 먼저 허용으로 바뀌어야 하고, 그다음 `SOURCES` 의 `enabled` 를 바꾼다.
