# Goal ({ROUND} 검토)
아래는 경제·시사 유튜브 생방송에서 진행자가 화면에 띄우고 읽을 발표 자료(덱)와 인용한 검증 기록이다. 너는 해석 점검자이자 구성 평가자로서 이 판을 비판적으로 읽어라.

# Context
- 덱의 화면·말에 나오는 수량은 전부 인용한 검증 기록의 원문 표기(observed)에서 왔다(단위 풀기·자릿수 표기 바꾸기만 `환산`으로 허용). 수치 옮겨 적기는 프로그램이 원문 사본과 대조했다.
- 부재 주장("…에 없다")은 그 문서의 원문 사본 전체를 다른 검토자가 읽어 대조한 결과다. 너에게는 사본을 주지 않으므로 범위 표현이 적절한지만 판단하라.
- 기사(언론 보도)는 숫자 근거가 아니다. 덱은 기사 내용을 숫자 없이 "기사"로만 쓴다(쪽의 `refs`). 인용한 기사 문장:
{PRESS}
- 덱이 지키려는 원칙: 원문에 없는 말을 보태지 않는다 / 회사의 주장·평가·전망은 그렇게 부른다 / 잠정치·미감사는 그렇게 적는다 / 기준이 다른 수치를 한 흐름으로 세우지 않는다 / 선후를 인과로 쓰지 않는다 / 없는 것은 어느 문서에 없는지 범위를 좁혀 말한다.
- 너에게 원문 문서는 주지 않는다. 판단은 아래 본문과 기록(observed, 메모)만으로 하라. 네가 아는 바깥 사실로 수치를 고치려 하지 마라.

# 해 달라는 것 — 네 절을 **모두** 끝까지 써라(요약만 쓰고 멈추지 마라)
1. 이전 판 지적이 풀렸는가(있을 때) — 항목마다 풀림 / 일부 남음 / 안 풀림과 근거 쪽.
2. 남았거나 새로 생긴 해석 문제 — 쪽·심각도(높음: 방송에 나가면 틀린 말이 되거나 오해를 부른다 / 중간 / 낮음)·근거. 없으면 "없음".
3. 구성 평가 — 중심 질문과 답의 정합, 반전이 실제로 뒤집는가, 한 장 한 가지, 한국 시청자 연결, 구어.
4. 최종 판정 — 이대로 방송 가능 / 아래를 고치면 가능(쪽 번호와 고친 문장, 새 수치 없이) / 불가. 취향 수준이면 "선택"으로 표시하라.

# Constraints
- 취향 수준의 문체 지적은 줄이고 내용과 구성에 집중하라. 근거 없이 "좋다"고 쓰지 마라. 확신이 없는 지적은 그렇게 표시하라.
