# 검토 지시서 틀

절차서 §5 의 판마다 함께 돌리는 검토 셋에 쓴다. 자리표시를 채워서 보낸다.

| 파일 | 누가 | 넘기는 것 |
|---|---|---|
| `sentence.md` | 문장 대조 — 덱을 쓰지 않은 다른 에이전트(읽기 전용) | 사양·쪽 그림·인용 기록·원문 사본·기사 사본 경로 |
| `composition.md` | 구성·화면 평가 — 다른 에이전트(읽기 전용) | 사양·쪽 그림 전부·러닝시트·평가 기준 |
| `external_head.md` | 해석 점검 — 다른 모델 계열 | 이 머리말 + `python -m ozl.render bundle <사양>` 으로 만든 묶음 |

자리표시: `{CARD}` 카드 ID · `{SPEC}` 사양 경로 · `{BUILD}` 빌드 폴더 · `{ROUND}` 몇 번째 판 · `{PREV}` 이전 판에서 짚은 것(없으면 줄을 지운다) · `{PRESS}` 덱이 인용한 기사 문장(없으면 줄을 지운다).

- 묶음과 이 지시서들은 독립 재대조(§5 4단계) 에이전트에게 주지 않는다.
- 영상 전사·영상 목록은 다른 모델 계열에 넘기지 않는다.
- 검토끼리 부딪히면 정확성이 이긴다. 다음 판 고쳐 쓰기 지시서에 "받지 않는 것"을 적는다.
- 마지막 판은 직전 판과의 차이를 보는 게이트를 돈다(`sentence.md` 를 쓰되 범위를 "바뀐 문장, 그리고 지우거나 옮긴 곳을 가리키는 남은 문장"으로 좁힌다).
