## 방법론 한눈에

| 출처 등급 | 정의 | 사용 규칙 |
|---|---|---|
| T1 | 1차 공식 통계·공시·원문 | 단독 사용 가능(단위·기준시점·개정 확인) |
| T2 | 국제기구·국책연구·동료심사 | 단독 사용 가능(방법론 병기) |
| T3 | 주류 언론 팩트 기사 | 2건 교차(동일 원출처는 1건) 또는 T1/T2 역추적 |
| T4 | 전문가 의견·리포트·프리프린트 | "주장·추정"으로만, 반대 시각 병기 |
| T5 | 커뮤니티·SNS·찌라시 | 인용·이미지 사용 금지, 소재 단서로만 |

- **`verified`** = ① 원본성(원문 직접 확인·아카이브) ② 정확성(재계산·단위·기준시점) ③ 해석(분모·비교군·인과) 통과 + **사람 육안 대조**. 모델 교차 검증은 보조 신호.
- 배지: `[공식 확인]` · `[외신 보도 종합]` · `[OOO 단독 / 반론 대기]` · `[주의: 사실 확인 안 된 루머]`
- 모든 카드에 **반증**(가장 강한 반례·잔여 불확실성)과 **"왜 오늘인가"** 를 적습니다.
- 공개 발행은 검증·승인된 카드만. 정정은 `docs/corrections.md`에 남깁니다.

전체 방법론: `docs/methodology.md` · 소스 카탈로그: `docs/sources.md` · 도구: `docs/tooling.md`
