# OZL — 오늘의 즐길거리

경제·국제·사회 뉴스에서 방송 한 꼭지로 다룰 만한 소재를 골라 카드로 적고, 통과시킨 소재를 생방송용 슬라이드로 만드는 개인 작업 기록입니다. 슬라이드의 숫자마다 그 숫자가 적힌 공식 원문의 대목을 검증 기록으로 남기고, 덱의 출처 부록에는 기록 번호와 원문 위치·링크를 붙였습니다. 공개하는 것은 제가 승인한 것뿐입니다.

## 먼저 볼 것

- [2026년 11월 10일 아침 회차 1번 카드](daily/2026-11-10_am.md#am-01). 미국 물가 발표에서 "1년 전보다 몇 % 올랐다"는 숫자가 빠지는 이유를 다뤘습니다.
- [그 카드의 검증 기록 11건](https://github.com/johyunbin/ozl/tree/main/claims/2026-11-10). 주장마다 원문 주소와 원문에 적힌 값을 적어 두었습니다. 이 회차의 기록은 제가 원문과 눈으로 대조했습니다.
- [작업 방식](how-it-works.md). 일이 어떤 순서로 도는지, 무엇이 자동이고 무엇을 직접 하는지, 첫 회차에서 무엇을 빼고 무엇을 공개하지 않았는지 적었습니다.
