# OZL — 오늘의 즐길거리

경제·국제·사회 뉴스에서 방송 한 꼭지로 다룰 만한 소재를 하루 두 번 골라 카드로 적는 개인 작업 기록입니다. 카드에 쓴 숫자는 기관 원문을 직접 열어 맞춰 본 것만 공개합니다.

- [그 카드의 검증 기록 11건](https://github.com/johyunbin/ozl/tree/main/claims/2026-11-10). 주장마다 원문 주소와 원문에 적힌 값을 적어 두었습니다.
